# Hướng dẫn tải ảnh phòng triển lãm

Vui lòng đặt các ảnh tương ứng với từng phòng vào thư mục này. 
Tên file: `room-0.jpg`, `room-1.jpg`, ..., `room-9.jpg`.

- `room-0.jpg`: Sảnh chính
- `room-1.jpg`: Khởi nguồn
- `room-2.jpg`: Tìm đường cứu nước
- ...

Nếu không có ảnh, hệ thống sẽ hiển thị một gradient thay thế.
